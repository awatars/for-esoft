Задание 3: Проверка правильности скобок

Алгоритм на основе стека проверяет, является ли строка из скобок ()[]{} правильной последовательностью. Временная сложность O(n), память O(n).

JavaScript 
/**
 * Проверяет, является ли строка правильной последовательностью скобок.
 *
 * Алгоритм: используем стек.
 * Встречая открывающую скобку, кладём её в стек.
 * Встречая закрывающую, проверяем, совпадает ли она
 * с верхним элементом стека (ближайшей непарной открывающей).
 * В конце стек должен быть пуст.
 *
 * Временная сложность:  O(n), где n это длина строки.
 * Пространственная:     O(n) в худшем случае (все открывающие).
 *
 * @param {string} s  строка из символов ()[]{}
 * @returns {boolean} true, если последовательность правильная
 */
function isValidBrackets(s) {

    // Соответствие закрывающей скобки открывающей
    const matching = {
        ')': '(',
        ']': '[',
        '}': '{'
    };

    const opening = new Set(['(', '[', '{']);
    const stack = [];

    for (const char of s) {

        if (opening.has(char)) {
            // Открывающая скобка: в стек
            stack.push(char);

        } else if (char in matching) {
            // Закрывающая скобка: проверяем вершину стека
            if (stack.length === 0 || stack[stack.length - 1] !== matching[char]) {
                return false;
            }
            stack.pop();
        }
    }

    // Стек должен быть пуст
    return stack.length === 0;
}
Сложность алгоритма:
Временная: O(n), один проход по строке, каждый символ обрабатывается за O(1).
Пространственная: O(n), в худшем случае все символы это открывающие скобки и попадают в стек.
